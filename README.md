# Travel Explorer App 🌍

A beautiful Flutter app to explore countries with real-time data.

## Features
- 🌍 Real-time country data (REST Countries API)
- 🔍 Search and filter by region
- ❤️ Save favorites
- 🔐 Local authentication
- 🎨 Modern glassmorphism UI

## Setup

```bash
flutter pub get
flutter run -d chrome
